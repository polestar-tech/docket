# Getting help with Docket

## First, try the guide

The user guide is inside the extension, with a short animation for every step: in the Docket sidebar, open the Tasks view's **…** menu → **Open User Guide**. Its last section, **Troubleshooting**, covers the most common problems, such as:

- the agent doesn't see Docket's tools;
- the Claude tab opens but nothing happens;
- a task queued later isn't picked up;
- Copilot uses the wrong account.

## Then, pick the right place

| Your question | Where |
| --- | --- |
| Something doesn't work | [Bug report](https://github.com/polestar-tech/docket/issues/new?template=bug_report.yml) |
| An idea or an improvement | [Feature request](https://github.com/polestar-tech/docket/issues/new?template=feature_request.yml) |
| "How do I…?" | [Discussions → Q&A](https://github.com/polestar-tech/docket/discussions/categories/q-a) |
| A security problem | Privately: see [SECURITY.md](https://github.com/polestar-tech/docket/blob/main/SECURITY.md) |
| Licences, billing or anything else | docket@polestartechno.com |

## What we answer

We reply to new issues and questions within a few working days. Docket is made by a small team, so we read everything but can't build every request. A 👍 on an existing issue tells us how many people need it.

## Problems with an agent

Docket hands your tasks to the agent you choose. If the agent itself misbehaves (it writes wrong code, hits its usage limit, or can't sign in), that belongs to its maker:

- Claude Code: [github.com/anthropics/claude-code/issues](https://github.com/anthropics/claude-code/issues)
- GitHub Copilot: in VS Code, **Help → Report Issue**, then choose the GitHub Copilot Chat extension.
- Other agents: their own websites or repositories.

If you're not sure whether the problem is Docket's or the agent's, report it here first.
